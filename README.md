# Happy 23rd Birthday Chandana! 🌸✨

A romantic, interactive 23rd birthday celebration web page created with love for Dr. Chandana.

## Features
- 🎂 Interactive 3D strawberry cake with blowable candles and cake-cutting ceremony
- 💖 Live romantic relationship counter (Days, Hours, Minutes, Seconds)
- 💌 Interactive "Why You're My Favourite" origami love jar
- 👑 25 photo polaroid memory gallery with zoom lightbox
- 💑 Couple scrapbook photo slider
- 📜 Animated wax-sealed love letter
- 🎁 Virtual birthday surprise gift box with vouchers
- 🎵 Procedural Web Audio romantic music box and chimes
- 🎆 Fullscreen particle, confetti, and fireworks animations

## Hosted on GitHub Pages
To enable GitHub Pages:
1. Go to **Settings** > **Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)` folder, then click **Save**.
4. The site will be live at: `https://moulyyy.github.io/Birthday/`
