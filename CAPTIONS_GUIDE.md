# 📸 Photo Captions & Notes Customization Guide

This file helps you easily customize captions for Dr. Chandana's birthday photos and love notes before deployment.

All captions are stored in [`captions.js`](file:///c:/Github/Birthday/captions.js). You can open [`captions.js`](file:///c:/Github/Birthday/captions.js) and edit the text inside `caption: "..."`.

## 📱 1. Her Phone Number (for direct WhatsApp & SMS wish)
In [`captions.js`](file:///c:/Github/Birthday/captions.js), find:
```javascript
const HER_PHONE_NUMBER = "91XXXXXXXXXX";
```
Replace `"91XXXXXXXXXX"` with Chandana's actual phone number including the country code (e.g., `"919876543210"` for India).
